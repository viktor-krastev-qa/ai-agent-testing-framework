# Прехвърляне на ZIP в клонираното repository

1. Разархивирай в отделна папка.
2. Копирай съдържанието в E:\GitHub\ai-agent-testing-framework. Не създавай втора вложена папка със същото име.
3. Замени README.md и .gitignore. Запази .git и съществуващия LICENSE.
4. В терминала създай средата с py -3.13 -m venv .venv и активирай с .\.venv\Scripts\Activate.ps1.
5. Изпълни командите от README за инсталиране, тестове и отчет.
6. Преди commit настрой локалните user.name и user.email с noreply адреса на новия GitHub профил; настройките от първия проект не се пренасят автоматично.
7. Ако git не се намира: $env:Path = "C:\Program Files\Git\cmd;$env:Path".

Записаните good plans включват и опасни опити: тестът минава, когато защитата ги блокира. Bad plans са действия, които не отговарят на конкретния сценарий. Нито един файл не е резултат от реален LLM.
